Multi-Role Portals & Operational Infrastructure

PHASE 1: OPERATIONS

2. Kitchen Display System (GDS / KDS)

👨‍🍳 Kitchen Kanban Board (KitchenBoardView.tsx, KitchenTicketCard.tsx)
• Live Prep Queue: Automatically groups incoming table orders by station (COFFEE, CHAI, FOOD) with distinct priority chips.
• Countdown Timers: Visual urgency indicator displaying elapsed prep time and automated target completion countdown.
• Station Routing: Barista and kitchen staff can mark items as "Cooking", "Ready for Pickup", or "Served".
• Realtime Audio / Visual Alerts: New orders trigger pulse animations to alert kitchen staff immediately.

3. Cashier Point of Sale (POS) & Settlement Queue

💵 Cashier Settlement Desk (CashierDashboard.tsx)
• Pending Table Queue: Instant visual overview of all occupied tables with unbilled balances, guest counts, and order status.
• Multi-Payment Clearance: Direct toggles for Cash, Card at Counter, or Verified UPI transactions.
• Discounts & Modifiers: Manager overrides for hospitality discounts, custom notes, and table session closure.
• Digital PIN Verification: Validates table PIN codes (e.g. 4821) before clearing active table sessions.

4. Admin Control Tower & Analytics

📊 Admin Executive Cockpit (AdminTowerDashboard.tsx, AdminLoginGate.tsx)
• Live Sales Telemetry: Realtime revenue KPIs (Gross Sales, Average Order Value, Table Turnover Rate, Peak Volume Hours).
• Menu Inventory Control: Instant toggle to mark ingredients or menu items as "86'd" (out of stock) across all customer QR sessions.
• Role Access Gate: Secure PIN/password authentication gate protecting administrative controls from customer access.

5. Realtime Synchronization & Event Bus

⚡ Simultaneous Sync Bus (sync-events.ts, table-tag.ts)
• Zero-Latency Coordination: When a customer places an order at Table 07, the order broadcasts instantaneously to the Kitchen KDS and Cashier POS.
• Session State Recovery: Reconnecting browsers automatically fetch the active session state and pending items.
